## ✿ Requisitos

- Node.js `v18+`
- Git
- FFmpeg (para comandos de audio/video)

---

## ✿ Instalación

```bash
git clone https://github.com/Zoredevteam-ctrl/masha-kujou-md
cd masha-kujou-md
npm install
```

---

## ✿ Iniciar

```bash
# Menú interactivo
node index.js

# Con código QR
node index.js --qr

# Con código de 8 dígitos
node index.js --code
```
